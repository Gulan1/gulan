    Server一些常用指令

    Gulan 11/10/2025 UbuntuServer

    # 查看目录大小

    # 查看当前目录下各子目录大小（限制深度为1）

    du -h --max-depth=1
    • -h：以"可读形式"显示（例如 KB、MB、GB）
    • max-depth=1：只显示当前目录下第一层子目录的大小

    # 查看指定目录的总大小

    du -sh /path/to/folder
    • 显示指定目录的总大小，-s 表示汇总，-h 表示人类可读格式。

    # 查看内存使用情况

    df -h

    # Screen 会话管理

    # 安装 Screen

    sudo apt install screen

    # 创建新会话

    screen -S mysession

    这会打开一个新的虚拟终端会话，可以在里面执行命令，例如：

    python myscript.py

    # 断开会话（不杀死程序）

    按下：Ctrl + A，然后按 D（detach）

    # 重新连接会话

    screen -r mysession

    这样就能接回之前的会话，看到程序的输出。

    # 管理多个会话

    创建多个会话时，使用不同的会话名称：

    screen -S session1
screen -S session2
screen -S session3

    查看所有会话列表：

    screen -ls

    连接到指定的会话：

    screen -r session1  # 连接到 session1
screen -r session2  # 连接到 session2
