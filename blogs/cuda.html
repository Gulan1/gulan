    CUDA安装

    Gulan 5/20/2025 UbuntuCUDA

    # 下载CUDA工具包

    首先，访问NVIDIA官方的CUDA工具包归档页面： https://developer.nvidia.com/cuda-toolkit-archive (opens new window)

    # 配置环境变量

    安装完成后，需要配置必要的环境变量。

    export PATH=$PATH:/usr/local/cuda/bin
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/cuda/lib64
export LIBRARY_PATH=$LIBRARY_PATH:/usr/local/cuda/lib64

    然后，使新的环境变量设置生效：

    source ~/.bashrc

    # 验证安装

    要验证CUDA工具包是否正确安装，请运行以下命令：

    nvcc -V

    如果安装成功，该命令将显示CUDA编译器版本信息，类似于：

    nvcc: NVIDIA (R) Cuda compiler driver
Copyright (c) 2005-2023 NVIDIA Corporation
Built on Xxx_Xxx_xx xx:xx:xx
Cuda compilation tools, release x.x, Vxx.x.x

    # 安装cuDNN

    cuDNN是NVIDIA专为深度学习优化的GPU加速库。以下是安装步骤：

    1. 访问NVIDIA的cuDNN下载页面： https://developer.nvidia.com/rdp/cudnn-archive (opens new window)

    2. 选择与您的CUDA版本兼容的cuDNN版本（需要NVIDIA开发者账户登录）。

    3. 下载后，解压文件：

      tar -xvf cudnn-linux-x86_64-8.9.7.29_cuda11-archive.tar.xz

    4. 复制文件到CUDA安装目录：

      sudo cp cudnn-linux-x86_64-8.9.7.29_cuda11-archive/include/* /usr/local/cuda-11.8/include
sudo cp cudnn-linux-x86_64-8.9.7.29_cuda11-archive/lib/libcudnn* /usr/local/cuda-11.8/lib64

    5. 设置正确的权限：

      sudo chmod a+r /usr/local/cuda-11.8/include/cudnn.h
sudo chmod a+r /usr/local/cuda-11.8/lib64/libcudnn*

    6. 验证cuDNN安装：

      cat /usr/local/cuda-11.8/include/cudnn_version.h | grep CUDNN_MAJOR -A 2

      正确安装后，此命令会显示cuDNN的版本信息。

    # 切换CUDA版本

    如果您的系统上安装了多个CUDA版本，可以通过以下步骤切换版本：

    1. 删除现有的CUDA软链接：

      sudo rm -rf /usr/local/cuda

    2. 创建指向所需CUDA版本的新软链接：

      sudo ln -s /usr/local/cuda-11.0 /usr/local/cuda

    3. 验证当前激活的CUDA版本：

      nvcc --version

    注意：切换CUDA版本后，可能需要重新配置相应版本的cuDNN。

    # 卸载CUDA

    如需卸载CUDA，请按照以下步骤操作：

    1. 使用CUDA卸载工具：

      cd /usr/local/cuda-11.0/bin
sudo ./cuda-uninstaller

    2. 删除CUDA安装目录：

      sudo rm -rf /usr/local/cuda-11.0

    3. 如果存在软链接，也应删除：

      sudo rm -rf /usr/local/cuda

    4. 编辑~/.bashrc或其他shell配置文件，移除之前添加的CUDA相关环境变量。

    # 可能的问题及解决方案

    • 如果nvcc -V命令未找到，请检查PATH环境变量是否正确设置。
    • 如果在编译CUDA程序时出现库相关错误，请检查LD_LIBRARY_PATH和LIBRARY_PATH是否正确设置。
    • 如果您的系统上已安装NVIDIA驱动，安装CUDA时跳过驱动安装是推荐的做法，以避免驱动冲突。
    • 确保cuDNN版本与您的CUDA版本兼容，不兼容可能导致深度学习框架无法正常工作。
    • 在切换CUDA版本后，记得检查深度学习框架是否需要重新编译或配置。
